# Tulas International School (TIS) - Homepage Redesign

A modern, animated redesign of the Tulas International School homepage focusing on high conversion, fluid animations, and mobile responsiveness.

## 🚀 Live Demo
- **Live URL:** [https://frontend-git-main-ommis-projects.vercel.app/](https://frontend-git-main-ommis-projects.vercel.app/)
- **Repository:** [https://github.com/rajtaru/TIS-FOLDER](https://github.com/rajtaru/TIS-FOLDER)

## 🛠️ Tech Stack
- **Framework:** React.js (Vite)
- **Styling:** Tailwind CSS (with Class-based Dark Mode)
- **Animations:** Framer Motion (`motion/react`) with spring physics
- **Deployment:** Vercel

## ✨ Standout Features Implemented
1. **Scroll Depth Progress Bar:** A smooth, spring-physics-powered progress indicator fixed to the top of the viewport using Framer Motion's `useScroll` and `useSpring`.
2. **Global Dark & Light Mode:** Custom React Context implementation with local storage persistence, seamlessly toggling Tailwind's `dark:` classes across all components.
3. **Interactive Scroll Animations:** Section reveals and card transitions powered by Framer Motion.
4. **Sticky Navigation & Layout Polish:** Optimized sticky positioning ensuring navigation bars sit cleanly below the progress indicator.
